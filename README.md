# Sistema Prioridade Social

Projeto em Java que calcula a prioridade de famílias para programas sociais.

## Critérios de Prioridade
- Renda per capita
- Número de dependentes
- Possui pessoa com deficiência  
- Tempo de desemprego
- Risco do bairro: alto, médio, baixo

## Tecnologias usadas
- Java
- POO: Encapsulamento, Classes, Getters
- ArrayList e Comparator

## Como rodar
1. Clone: `git clone https://github.com/EdsonFerraoDev/sistema-prioridade-social`
2. Abra no VS Code
3. Execute a classe Main
